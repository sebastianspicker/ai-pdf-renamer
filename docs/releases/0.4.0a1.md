# Folionym 0.4.0a1

This alpha candidate provides supervised local PDF naming through the CLI,
Textual terminal interface, browser interface, and undo command. It is not
evidence that a GitHub prerelease has been published.

## Installation from GitHub assets

If the prerelease is published, download its wheel, source distribution, and
`SHA256SUMS` into one directory. Verify the artifacts, then install the wheel:

```bash
shasum -a 256 -c SHA256SUMS
python3.14 -m pip install \
  './folionym-0.4.0a1-py3-none-any.whl[pdf,tui,web]'
```

This version is not documented as a package-index release.

## Included interfaces

- `folionym` for batch, manual single-file, and watch operation
- `folionym-tui` for directory Preview, exact reviewed Apply, and confirmed
  immediate single-file rename
- `folionym-web` for loopback Source, Preview, and exact reviewed Apply
- `folionym-undo` for compatible same-directory rename logs

Optional extras add OCR, token-aware limits, the TUI, and the browser service.
OCR also requires OCRmyPDF platform prerequisites. Vision requires a compatible
model at the configured HTTP endpoint.

The reconstructed package groups configuration, naming, extraction, LLM,
application orchestration, filesystem mutation, infrastructure, and interfaces
behind stable public facades. Browser and directory TUI share immutable
application reviewed plans; exact Apply validates sources and targets without
another naming pass.

## Limitations

- CPython 3.14 or later is required; release verification uses 3.14.6.
- Run one process per target directory and retain backups for important files.
- The application does not sandbox PDF or OCR processing. There is no hard
  input byte limit, default page extraction is unlimited, workers have no hard
  maximum, and OCR has no application-level timeout.
- Directory TUI material edits invalidate its Preview, and cancelled Preview
  cannot Apply. TUI Rename one PDF uses immediate unique-available naming.
- CLI dry-run and apply are independent recomputing runs; `--plan-file` exports
  proposals only.
- Browser plans and reports last only for the current server process.
- Remote LLM endpoints and hooks can receive document-derived content or
  metadata. Use HTTPS and review the [security policy](../../SECURITY.md).
